
## Product Page Description:
The TCS34725 is a compact, high-accuracy colour sensor module that can detect the colour of objects with precision. It features an integrated IR-blocking filter to minimize interference from ambient infrared light, ensuring reliable and consistent colour readings. Two onboard white LEDs provide consistent illumination, while the built-in logic level converter allows for seamless compatibility with both 3.3V and 5V microcontrollers.  

Ideal for applications such as RGB LED control, colour temperature analysis, fluid or gas identification, ambient light sensing, and automated colour sorting systems.

## Quick Spec

- Supply Voltage: 3.3V–5.5V DC
- Logic Level: 3.3V / 5V
- Sensor Chip: TCS34725
- Communication Interface: I2C (Fast Mode Compatible)
- I2C Address: 0x29
- Integrated Features:
- Onboard white LEDs for active illumination
- Infrared-blocking filter for accurate visible light sensing
- Dimensions: 31.3 x 11mm
